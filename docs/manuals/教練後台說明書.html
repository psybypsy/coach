你的角色與這份指南

你同時是「教練」，也是一位「會自己書寫的成員」

身為 Ipsen Taiwan 計畫的教練，你在同一個平台上擁有兩種身分：你可以像一般成員一樣書寫、逛社群；也能進入教練專屬的 Coach Dashboard，查看所有學員的書寫、生成情緒分析、撰寫回饋、並產出交付給學員的正式報告。

這份指南聚焦在教練後台。一般成員介面（每週 5 題書寫、社群互動）的操作，請參考另一份《使用者介面說明書》。

i

本指南的畫面示意，取自實際的 Testing 測試環境操作，並以系統預設的英文介面呈現（右上角選單可切換繁體中文）。示意中的學員名稱、內容皆為測試資料。

登入與進入教練後台

從打開網站，到站在 Coach Dashboard 前的完整路徑
  1. 開啟網站：在瀏覽器輸入 coach-roan-eta.vercel.app 並前往。未登入會自動導向登入頁。
  2. 用 Email 登入連結進入 App：輸入你的 Email → 按 Send login link → 到信箱打開主旨「Your sign-in link」的信 → 點信中的 Sign in。 此連結一次性、會過期，請直接在信中點擊。
  3. 登入後會先落在「成員首頁」（PERMA Self-Reflection）。系統不會自動把你丟進教練後台——這是刻意的，讓你也能正常瀏覽成員介面。
  4. 點導覽列右側的 Coach Dashboard 按鈕，即進入教練後台。這顆按鈕只有教練帳號看得到。

4

成員分析頁

生成情緒分析，並用六組圖表讀懂一位學員的歷程

點進一位學員後，頁面由三大可收合區塊組成：Coach Deep Analysis（教練深度分析）、Client Deliverable（客戶交付版）、Entry timeline（書寫時間軸）。本節先談深度分析。

4.1生成分析

在 Coach Deep Analysis 區塊，按 Generate valence analysis & brief（生成情緒分析與情報簡報）。系統會逐週分析該學員的回饋，產出情緒 valence 評分與一份情報簡報。分析完成後，按鈕會變成 Regenerate analysis（重新生成分析），旁邊顯示 Based on N weeks（基於 N 週）。

i

學員至少要有 1 次書寫才能生成。這份深度分析僅教練可見，學員本人看不到。

4.2內文語言：EN / 中文

分析內文預設以英文生成（原生語言）。右上的 Text language 切換鈕：EN 即時顯示原文；點 中文 會即時翻譯一次並快取，之後切換即時。數字與圖表不受語言影響，只有文字敘述會翻譯。

!

要手動編輯簡報內文時，請先切回 EN——只有英文原文可編輯；中文為翻譯版，編輯鈕會停用（提示「Switch to EN to edit the source text」）。

4.3六組圖表 · 每組都可勾選「納入客戶版」

分析下方是六組視覺化圖表。每組標題左側的三角形可展開／收合；右側的 Include in client version 核取方塊，決定這張圖要不要放進給學員的客戶版報告。

手動修改回饋

AI 產出是草稿——你可以親手改寫任何一段

情報簡報是輔助你的草稿，最終回饋由你決定。展開任一區塊，點右下的 Edit（編輯），內文會變成可編輯的文字框；改寫完成按 Save（儲存） 即覆寫並保存，或按 Cancel 放棄。

7

檢查學員原文

回到第一手資料：學員到底寫了什麼

分析與簡報都是經過詮釋的結果。要核對第一手內容，請看成員頁最下方的 Entry timeline（書寫時間軸）。這裡逐筆列出該學員所有的書寫，依時間由新到舊排列。

每一筆會標示：所屬面向（P/E/R/M/A，以專屬顏色的標籤呈現）、書寫日期、以及學員的原始文字。若某筆內容被學員設為私人，會多一個 Private（私人） 標籤。你能看到全部內容（含私人），這是教練專屬的權限。

8

客戶交付版與 PDF

把你挑選的內容，變成一份給學員的正式報告

8.1先勾選、再生成

客戶版的內容，完全由你在深度分析裡的勾選決定：每個簡報區塊的 Include in client deliverable、每張圖表的 Include in client version，勾起來的才會進客戶版。Client Deliverable 區塊會顯示目前納入的區塊數（例如林思妤此例為 Blocks included: 4 / 8）。

  1. 確認勾選：回到深度分析，勾好你想給學員看的區塊與圖表，取消不想給的。
  2. 生成：在 Client Deliverable 按 Generate client deliverable（生成客戶交付版）。系統會把勾選的區塊，改寫成給學員本人、溫暖第二人稱的正式回顧文件。改了勾選想更新，按 Regenerate client version 重生成。
  3. 檢視：報告會顯示在下方（見圖 8），含標題、學員名字與日期、正文，以及你勾選納入的「情緒歷程一覽」圖表，最後署名 Coach · Tan Yee Ming。
!

至少要有 1 個區塊被納入，才能生成客戶版。Coach only 的區塊與未勾選的圖表不會出現在學員的報告裡。

8.3匯出 PDF

報告生成後，Client Deliverable 會多一顆 Print / Export PDF（列印 / 匯出 PDF）。按下它會開啟瀏覽器的列印對話框，而且已特別設定成只輸出這份客戶報告（頁面其他內容不會被印出）。

  1. 按 Print / Export PDF，開啟列印對話框。
  2. 在「目的地 / Destination」選擇 另存為 PDF（Save as PDF）。
  3. 按儲存 / Save，選擇存檔位置，即可得到一份可寄給學員的 PDF。
✓

想直接印在紙上，同一個對話框選實體印表機即可。若預覽出現多餘內容，確認你是從報告下方的 Print / Export PDF 按鈕進入（而非瀏覽器選單的列印）。

9

每週工作流程與 FAQ

一套可重複的節奏，讓後台工作更輕鬆

建議的每週節奏

  1. 看儀表板：掌握本週誰寫了、寫了幾篇、五維度分布。
  2. 逐一點進學員：對有新書寫的學員按 Regenerate analysis 更新分析。
  3. 對照原文：用 Entry timeline 核對語氣與脈絡。
  4. 整理回饋：編輯簡報區塊、調整 Include / Coach only 勾選。
  5. 交付：生成客戶版 → 匯出 PDF → 寄給學員或於會談中使用。
學員看得到我的深度分析或「Coach only」內容嗎？
看不到。深度分析、逐週評分、以及所有 Coach only 區塊都僅教練可見。學員只會收到你生成、且明確勾選納入的客戶交付版。
重新生成分析會蓋掉我手動改過的內文嗎？
會。Regenerate analysis 會以最新資料重跑，覆蓋既有的簡報內文與翻譯快取。若你已手改過想保留的段落，建議先複製保存，或改用「重新生成客戶版」只更新交付文件。
切到「中文」後不能編輯？
正確。中文是英文原文的即時翻譯版，為避免原文與譯文不同步，編輯只在 EN 模式開放。切回 EN 即可編輯。
儀表板沒即時更新？
儀表板會在學員發布時即時重整；若沒動，切回該分頁或視窗、或按導覽列的重新整理鈕，即會重新抓取最新資料。
PDF 印出來有多餘內容？
請務必從客戶報告下方的 Print / Export PDF 按鈕進入列印——它已設定成只輸出報告區。若用瀏覽器選單的列印，可能會印到整頁。
